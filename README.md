# Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de aplicar conceitos de estatística e análise de dados utilizando Python.

A ideia principal foi analisar informações reais sobre missões espaciais, observando padrões relacionados à quantidade de lançamentos ao longo dos anos e aos custos dos foguetes utilizados nas missões.

Para isso, foi utilizada uma base de dados pública disponível no Kaggle, permitindo trabalhar com dados reais e aplicar técnicas de análise estatística e visualização gráfica.

---

# Base de Dados

A base utilizada no projeto foi obtida no Kaggle:

* `Space_Corrected.csv`

Ela contém informações sobre:

* lançamentos espaciais;
* datas das missões;
* custos dos foguetes;
* empresas responsáveis pelos lançamentos;
* locais das missões.

---

# Tecnologias Utilizadas

Durante o desenvolvimento do projeto foram utilizadas as seguintes tecnologias:

* Python
* Pandas
* Matplotlib

---

# O que o código faz

O código realiza diversas etapas de análise estatística, incluindo:

* leitura da base de dados;
* tratamento e organização das informações;
* conversão de datas;
* cálculo de frequência absoluta, relativa e acumulada;
* análise estatística descritiva;
* geração de gráficos;
* interpretação básica dos resultados.

Além disso, o projeto calcula automaticamente:

* média;
* mediana;
* moda;
* variância;
* desvio padrão;
* quartis;
* amplitude dos dados.
